# Bold Bitcoin Wallet Documentation

This repository contains the documentation for Bold Bitcoin Wallet, automatically synced with [GitBook](https://docs.boldbitcoinwallet.com/).

## Repository Purpose

This repository is dedicated to documentation and is synced with GitBook for automatic publishing. All documentation updates should be made here and will automatically sync to GitBook.

## Structure

- `README.md` - Main documentation content (synced to GitBook)

## Updating Documentation

1. Edit `README.md` in this repository
2. Commit and push changes
3. GitBook will automatically sync within a few minutes
4. Review and publish in GitBook
